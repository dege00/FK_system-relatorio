# Sistema Automático de Relatórios

### Automação de Relatórios de Podas e Obras

<br>

**Sistema desenvolvido em Python para automatizar a geração de relatórios técnicos, organizando evidências fotográficas e preenchendo documentos Word de forma automática.**

---

# Sobre o Projeto

Este projeto nasceu de uma necessidade real do meu dia a dia profissional.

Grande parte do tempo era gasto organizando fotografias, preenchendo documentos e montando relatórios manualmente. Como muitas dessas tarefas eram repetitivas, decidi desenvolver uma ferramenta capaz de automatizar esse processo e tornar o trabalho mais rápido, organizado e padronizado.

O sistema foi criado inicialmente para relatórios de Podas e posteriormente expandido para atender também relatórios de Obras.

---

# Funcionalidades

- Geração automática de relatórios de Podas
- Geração automática de relatórios de Obras
- Organização automática das evidências fotográficas
- Preenchimento automático de documentos Word (.docx)
- Interface gráfica desenvolvida em Python
- Modo Claro e Modo Escuro
- Sistema de Logs
- Geração de executável para Windows

---

# Tecnologias Utilizadas

- Python
- CustomTkinter
- Python-Docx
- Pillow

# Objetivo

Este projeto foi criado sem fins lucrativos.

Seu principal objetivo é auxiliar nas atividades realizadas durante minha rotina de trabalho, reduzindo tarefas repetitivas e aumentando a produtividade na elaboração de relatórios técnicos.

Além disso, o projeto também serviu como uma grande oportunidade de aprendizado na área de programação e automação de processos.
